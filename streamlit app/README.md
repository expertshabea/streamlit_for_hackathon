# FoodFlow Analytics Streamlit App

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload the provided food-delivery CSV when the app opens.

## Features

- Delivery KPI dashboard
- Traffic impact analysis
- Distance vs delivery time
- Weather × traffic analysis
- Q1, Q2 and Q3 competition answers
- Three business insights
- Gemini AI-powered explanation
- Interactive filters
- Data explorer
- Filtered CSV download

## AI

The primary analysis is performed with Python and Pandas. Gemini receives the calculated results and explains them in business language. The API key is entered securely in the Streamlit interface and is not hard-coded.
